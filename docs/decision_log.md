# 의사결정 기록

분석하면서 정한 기준과, 멘토 피드백이나 새로 발견한 문제 때문에 바꾼 결정을 모았다.

## 분석 기준

| 결정 | 이유 | 문서 |
|---|---|---|
| 분석 기간 2017.01\~2018.08 | 2016년과 2018.09 이후는 월 주문이 0\~324건으로 수집이 끊김 | [01](01_data_preparation.md) |
| 고객 = `customer_unique_id` | `customer_id`는 주문마다 새로 생겨 모든 고객이 1회 구매로 보임 | [01](01_data_preparation.md) |
| 거래액 = 상품 가격 합계 (배송비 제외) | 판매 규모를 보기 위함. 결제액과 합계 차이는 0.02% | [01](01_data_preparation.md) |
| 여러 테이블은 주문 단위로 먼저 합친 뒤 JOIN | 바로 붙이면 매출이 27% 부풀려짐 | [01](01_data_preparation.md) |
| 퍼널은 주문 상태가 아니라 날짜 유무로 판단 | 상태와 날짜가 맞지 않는 주문이 있음 | [03](03_funnel_delivery.md) |
| 지연 = 실제 도착일 > 예상 도착일 (날짜만 비교) | 시각까지 비교하면 당일 도착이 지연으로 잡힘 | [03](03_funnel_delivery.md) |

## 피드백과 발견으로 바꾼 것

| 계기 | 확인한 것 | 결정 | 문서 |
|---|---|---|---|
| 멘토: 배송비가 상품마다 붙는지, 주문마다 붙는지 확인 | 상품가 합 + 배송비 합 = 결제 금액인 주문 99.75% | 주문 배송비 = 주문별 배송비 합계 | [01](01_data_preparation.md) |
| 멘토: 금액 기준 무료배송이 있는지 확인 | 무료배송 0.3%, 금액과 무관 | 배송비는 구매 금액과 상관없이 붙는 것으로 보고 분석 | [02](02_eda.md) |
| 같은 날 재구매가 30%로 너무 많음 | 90%가 10분 안, 결제수단 99% 같음 | 같은 날 주문은 재구매에서 제외 (재구매율 3.0% → 2.1%) | [04](04_repurchase.md) |
| 늦게 처음 산 고객의 재구매율이 낮게 나옴 | 고객마다 관찰 기간이 다름 | 첫 주문 2017.01\~2018.02 고객만, 180일씩 관찰 | [04](04_repurchase.md) |
| 2016년에 산 고객이 첫 구매 고객으로 섞임 | 분석 기간 안에서만 첫 주문을 찾았음 | 전체 주문 중 가장 이른 주문을 첫 주문으로 | [01](01_data_preparation.md) |
| 멘토: 권역별 객단가·주문 빈도 확인 | 1인당 주문 수는 모든 권역 약 1.03회 | 권역 차이는 빈도가 아니라 고객 수·객단가에서 남 | [02](02_eda.md) |
| 쿠폰 발급 시점 | 180일 재구매의 33%가 첫 30일에 발생 | 배송 완료 직후 발급 | [05](05_ab_test_design.md) |
| SQL을 돌릴 때마다 대상 고객이 37,210명 / 37,211명으로 바뀜 | 같은 시각에 주문이 2건 있는 고객 281명 | 정렬 기준에 `order_id`를 추가해 첫 주문 고정 | [05](05_ab_test_design.md) |
| 시드별 1회 실험 결과가 크게 흔들림 | 재구매 고객이 A/B에 나뉘는 운에 따라 B ÷ A가 1.10\~1.93배 | 1,000번 반복으로 검정력 확인 | [05](05_ab_test_design.md) |
| 배정을 고정하면 검정력이 1\~100%로 달라짐 | 고정하면 그 배정 하나의 검정력만 나옴 | 매 반복마다 배정과 주입 모두 새로 | [05](05_ab_test_design.md) |
| 검정력 72.4%로 목표 미달 | 대상이 180일 분석 기준으로 잡혀 있었음 | 주 지표(30일)에 맞춰 대상 재정의 → 58,071명, 88.7% | [05](05_ab_test_design.md) |
| 시뮬레이션 B ÷ A를 회차별 비율의 평균으로 계산 | 비율의 평균은 위로 치우침 | B 평균 ÷ A 평균으로 계산 | [05](05_ab_test_design.md) |
| 유효기간 14일 vs 30일 | 14일은 검정력 68.5% | 유효기간 30일 쿠폰 | [05](05_ab_test_design.md) |
